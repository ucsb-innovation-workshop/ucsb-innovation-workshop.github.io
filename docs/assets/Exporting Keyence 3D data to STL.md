# Keyence 3D Image to STL

> **Important:** 3D data must be collected using **"Depth Up"** on the Keyence microscope.

**[Keyence Software for Conversion](https://drive.google.com/drive/folders/1iVN1yk9f39hcIrFkHzkHuAN27g0ST3jN?usp=sharing)**

The Keyence microscope can use its motorized objective and focus sensing to create 3D depth maps by scanning the focal point of the microscope up and down across the sample.

This 3D data is saved within the `.jpg` or `.tiff` file and must be exported to a `.csv` file before converting it to an STL.

---

## Exporting `.csv` Data from `.jpg` or `.tiff`

Obtaining 3D data from these files requires the Keyence software. This software is available on the computer used for the CNC mill.

To find the software:

1. Open the **Windows Search** bar.
2. Search for **`vhx3d`**.
3. Open the Keyence software.

![Finding the Keyence software](/docs/assets/findsoftware.jpg)

Once the software is open, it will prompt you to select a file containing 3D data.

1. Select the `.jpg` or `.tiff` file containing the 3D data.
2. Select **Save CSV**.
3. Choose where you want to save the `.csv` file.

![Exporting CSV data](/docs/assets/exporting_data.jpg)

The exported `.csv` file contains height data in **microns (µm)**.

No X or Y data is provided in the CSV file. For the X and Y dimensions, refer to the Keyence microscope datasheet for the corresponding **3D pixel size**.

---

## Converting the CSV Data to STL

The CSV data can be converted into an STL mesh using MATLAB.

### 1. Download the MATLAB Scripts

Download the following MATLAB scripts:

* `surf2stl.m`
* `stl_maker.m`

Make sure both scripts are located in the **same folder as the exported `.csv` file**.

### 2. Open MATLAB

Launch MATLAB and open the `stl_maker.m` script.

### 3. Set the CSV File Path

Change the file path inside `stl_maker.m` so that it points to the exported `.csv` file.

![Changing the CSV file path](/docs/assets/urfilename.jpg)

### 4. Run the Script

Run `stl_maker.m`.

MATLAB will automatically generate the STL file and save it to:

```text
This PC → Documents → MATLAB
```

The generated STL will use the CSV filename with `_STL` appended to it.

For example:

```text
sample.csv
```

will generate:

```text
sample_STL.stl
```

### 5. Import the STL

The exported STL is a **mesh file representing the surface scan** generated by the Keyence microscope.

The STL can be imported into **SolidWorks** or another mesh-editing program. From there, additional surfaces can be created and the mesh can be closed if a solid model is needed for 3D printing.

---

## Workflow Summary

```text
Keyence Microscope
       ↓
Capture 3D Data using "Depth Up"
       ↓
Save as .JPG or .TIFF
       ↓
Open with Keyence VHX3D Software
       ↓
Save CSV
       ↓
CSV Height Data
       ↓
MATLAB (stl_maker.m + surf2stl.m)
       ↓
STL Mesh
       ↓
SolidWorks / Mesh Editor
       ↓
Closed Solid / 3D Printable Model
```

### Required Files

| File             | Purpose                                    |
| ---------------- | ------------------------------------------ |
| `.jpg` / `.tiff` | Keyence image containing embedded 3D data  |
| `.csv`           | Height data exported from Keyence software |
| `stl_maker.m`    | MATLAB script used to generate the STL     |
| `surf2stl.m`     | MATLAB function used by `stl_maker.m`      |
| `.stl`           | Final surface mesh                         |

