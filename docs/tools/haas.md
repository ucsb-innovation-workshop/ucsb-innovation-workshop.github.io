**Tool Type:** CNC Milling Machine  
**Manufacturer:** Haas  
**Location:** Elings 3430  

## Safety Concerns

* Safety glasses must be worn when the machine is running.
* The glass doors must be closed before starting a job.
* The spindle must be completely stopped before adjusting or removing the workpiece or tool.
* Milled parts may have sharp burrs. Remove burrs with a hand file or sandpaper.
* Proof your program before running it. The first time you run a program, slow the rapid speed and stay by the control panel.
* Use single-block mode when running a program for the first time.

## Typical Use Cases

* CNC milling
* Machining prototypes and custom parts
* Producing parts from CAD models
* Drilling, milling, and tapping operations

## Specifications

* **X-axis travel:** 16"
* **Y-axis travel:** 12"
* **Z-axis travel:** 10"
* **Spindle nose to table:** 14" max, 4" min
* **Table length:** 36"
* **Work area length:** 28.75"
* **Table width:** 12"
* **T-slot width:** 12"
* **T-slot center distance:** 4.33"
* **Number of T-slots:** 3
* **Maximum table load:** 500 lb
* **Spindle power:** 15 hp
* **Maximum spindle speed:** 10,000 rpm
* **Maximum torque:** 17 ft-lb @ 4600 rpm
* **Taper:** 40
* **Rapid traverse:** 1200 in/min
* **Maximum cutting feed:** 833 in/min
* **Maximum thrust:** 2000 lb
* **Maximum tool diameter:** 3.5"
* **Automatic tool changer:** 10-station
* **Power:** Three-phase
