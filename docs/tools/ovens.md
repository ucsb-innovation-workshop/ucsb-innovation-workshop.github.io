## Safety Concerns

The following precautions apply to both ovens:

- **High Voltage:** Do not operate an oven if it is damaged or malfunctioning. Place a note on the oven to alert other users and notify laboratory staff.
- **High Temperature:** Wear thermally insulating gloves when handling hot items. Gloves are usually located on the bench next to the ovens.
- Do not place combustible or hazardous materials in either oven.
- No food may be placed in laboratory ovens.
- Never heat a sealed container.
- **Secondary containment is required when heating containers of liquid** to prevent leaks from contaminating the oven. This is especially important when heating PDMS molds.

## Typical Use Cases

- Heating samples and materials approved for oven use.
- Heating PDMS molds with appropriate secondary containment.

The Lindberg Blue M convection oven uses a motorized fan to circulate air throughout the chamber for quick and uniform heating.

**Training is required to use these tools.**

Please refer to our SOP if you need a refresher:

- [Laboratory Oven SOP](../SOPs/ovens_SOP.md)

### Operating Procedures — Both Ovens

1. Enter the desired temperature set point using the instructions below.
2. Place your items in the oven. Place liquid-containing materials on a baking sheet or other secondary container.
3. Set the countdown timer for the length of your run using the instructions for the appropriate oven. If the timer reads zero, another user who needs the oven may remove your items.
4. When finished, remove your items and close the door.
5. Leave the oven powered on.

### Changing the Temperature Set Point — Both Ovens

1. Use the **↑ / ↓** buttons to adjust the temperature.
2. Press **SET/ENT** to confirm.

### Countdown Timer — Lindberg Blue M Convection Oven

1. Press **1**.
2. Enter the run time using the **H / M / S** buttons.
3. Press **1** to start the countdown.
4. Press and hold **1** to reset the timer.

### Countdown Timer — Thermoline / Lindberg Blue M Oven

1. Make sure the slide switch on the right is set to **Countdown**.
2. Enter the run time using the **H / M / S** buttons.
3. Press **Start/Stop** to start the countdown.
