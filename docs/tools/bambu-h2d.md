## Specifications  

* **Nozzle tip sizes:** 0.2 mm nozzle, 0.4 mm nozzle, 0.6 mm nozzle
* **Single Nozzle Build volume:** 325 mm x 320 mm x 325mm
* **Dual Nozzle Build volume:** 300 mm x 320 mm x 325mm
* **X,Y accuracy: ~200 microns Max Nozzle Temp:** 350 C Max Heatbed Temp: 120 C Max Chamber Temp: 65 °C
